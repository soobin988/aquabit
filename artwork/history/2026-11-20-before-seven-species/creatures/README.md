# 사용자가 준비한 생물 이미지

`public/play/assets/`에 넣은 PNG 12종을 **바이트 변경 없이** 이 폴더에 복사했습니다. 파일명과 원본 크기(640×400)를 유지하며, 화면에서만 비율을 유지해 축소·확대합니다. 쓰레기(1)·쓰레기(2)는 생물 선택에서 제외했습니다.

이제 원본을 수정할 때는 **이 폴더**의 같은 파일을 편집하세요. `npm run build` 또는 `npm start`를 실행하면 `public/play/assets/creatures/`로 복사되어 게임에 반영됩니다. `public/play/`는 빌드 결과이므로 이곳에만 새 파일을 넣으면 다른 컴퓨터로 옮길 때 빠질 수 있습니다.

종류·파일 연결은 `game/domain/creatures.json`에서 관리합니다. 현재 각 종류에 이미지 한 장을 사용하며, 이전에 생성한 물고기 이미지는 게임에서 불러오지 않습니다. 예전 저장 데이터의 물고기 ID·이름·경험치는 유지하고 옛 종류만 새 종류로 연결합니다.
