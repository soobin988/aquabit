# 첨부한 새우 그림 직접 적용

사용자가 마지막에 첨부한 그림을 `source.png`에 변경 없이 보관했습니다. 새로 생성하거나 팔레트를 바꾸지 않고 왼쪽·오른쪽을 나눠 `frames/shrimp.png`, `frames/shrimp-2.png`로 저장했습니다. 기존 128픽셀 이하 편집 조건에 맞춰 각 프레임을 **96×64**로 최근접 축소했으며 가로세로 비율과 투명도를 유지합니다.

실제 게임 파일은 `game/public/assets/creatures/shrimp.png`, `shrimp-2.png`입니다. 확대 검토용은 `preview.png`입니다. 다른 6종 이미지는 변경하지 않았습니다.
